## 1. 先把问题写成一个决策

普通响应预测问：`P(Y=1 | X=x)` 高不高？例如“谁本来就最可能购买”。Uplift 问：对同一个特征人群，触达相对不触达让结果改变多少？

记号：

- `i`：一名客户；`X_i`：发邮件前已经知道的属性。
- `T_i ∈ {0,1}`：是否发送 Mens E-Mail。
- `Y_i(1)`：如果发送，客户的转化结果；`Y_i(0)`：如果不发送，客户的转化结果。
- 观测结果：`Y_i = T_i Y_i(1) + (1-T_i)Y_i(0)`。
- 个体处理效应：`tau_i = Y_i(1)-Y_i(0)`。
- 平均处理效应：`ATE = E[Y(1)-Y(0)]`。
- 条件平均处理效应：`CATE(x) = E[Y(1)-Y(0) | X=x]`。

这里最重要的区别是：`Y(1)` 和 `Y(0)` 是同一人的两个可能世界，而不是 treated 和 control 中两个不同人的普通标签。一个人最终只能走进一个世界，所以只看到其中一个，另一个是 counterfactual。这就是因果推断的基本问题。因此监督式 Uplift 模型学的是可识别条件下的 CATE 或排序信号，不是拿到每个人的真实 ITE 标签。

### 引导手算例 1（有答案）

假设四名客户的潜在转化如下：

| 客户 | `Y(1)` | `Y(0)` | ITE |
|---|---:|---:|---:|
| A | 1 | 0 | +1 |
| B | 1 | 1 | 0 |
| C | 0 | 0 | 0 |
| D | 0 | 1 | -1 |

如果 A、B 被随机到邮件组，我们观察 A=1、B=1；C、D 被随机到对照组，我们观察 C=0、D=1。四个观测标签是 `[1,1,0,1]`，但没有任何一行同时暴露两个潜在结果。即使 A 和 B 都在邮件后购买，邮件对 A 有正效果，对 B 没效果；响应标签无法区分二者。

## 2. 四类人群和广告/增长含义

| 类型 | `(Y(1),Y(0))` | ITE | 业务含义 |
|---|---|---:|---|
| persuadable | `(1,0)` | +1 | 只有触达才转化；优先触达 |
| sure thing | `(1,1)` | 0 | 无论如何都会买；触达可能浪费预算 |
| lost cause | `(0,0)` | 0 | 触达也不买；浪费预算 |
| harmed / sleeping dog | `(0,1)` | -1 | 触达反而阻止转化；应抑制触达 |

这张表是概念工具，不表示现实中能给每名客户观测分类。对二元结果，模型最多从群体规律估计 `CATE(x)`。

广告例子：高品牌忠诚客户的自然购买率可能是 80%，广告后仍为 80%。响应模型会把她排在最前面，Uplift 是 0。另一个边缘客户自然购买率 10%，看广告后 25%，响应概率仍低于 80%，但增量为 +15 个百分点，更值得有限曝光。若广告造成反感，使购买率从 20% 降到 12%，Uplift 为 -8 个百分点，更多曝光会伤害目标。

### 引导手算例 2（有答案）

两个特征群：

- 忠诚用户：`P(Y(1)=1|X)=0.82`，`P(Y(0)=1|X)=0.80`，CATE=`0.02`。
- 犹豫用户：`P(Y(1)=1|X)=0.30`，`P(Y(0)=1|X)=0.10`，CATE=`0.20`。

预算只能覆盖一群。响应排序选忠诚用户（0.82 更高）；增量排序选犹豫用户（0.20 更高）。若每群 1,000 人，忽略成本，前者期望新增 20 次转化，后者 200 次。不要把 `0.20` 解释成每个犹豫用户的确定 ITE；它是该特征群的平均差。

## 3. 什么让平均差有因果含义

在随机实验中，处理分配与潜在结果在概率上独立：`T ⟂ (Y(1),Y(0),X)`。因此在足够大且执行良好的样本里，treated 的平均 `Y` 可以估计 `E[Y(1)]`，control 的平均 `Y` 可以估计 `E[Y(0)]`，两者之差估计 ATE。随机化解决的是处理选择与潜在结果的系统混杂，不是让两个潜在结果同时可见。

还需能说清：

- consistency：实际接受处理 `t` 时，观测结果等于对应的 `Y(t)`；“发邮件”必须定义足够一致。若有人只被分配却未送达，需区分 assignment 与 receipt 的 estimand。
- SUTVA 的处理版本：处理没有隐藏版本；一个人的潜在结果不因别人的处理而改变。
- overlap/positivity：对所讨论的 `X=x`，处理与对照都有正概率。随机三臂设计通常支持总体 overlap，但极小子群仍可能样本稀疏。
- no interference：A 收到邮件不会改变 B 的结果。社交推荐、共享家庭账户、广告竞价拥挤都可能违反它。

### 观测混杂反例

运营人员只给最近活跃用户发券。券组转化 20%，非券组 5%，不能直接说券增量 +15pp，因为活跃度同时影响发券和购买。即使回归控制一些特征，未观测购买意愿仍可能混杂。随机化把已知和未知混杂在期望上打散，这正是 Hillstrom 数据的价值。

### 随机化没有自动修复什么

- post-treatment leakage：把 `visit` 放进模型预测 `conversion`；visit 已受邮件影响。
- attrition / missing outcome：两组结果丢失机制不同。
- measurement error：转化归因、邮件送达记录错误。
- multiple testing、稀疏结局和小子群高方差。
- interference、处理定义不一致、实验到部署的人群漂移。
- 离线估计不能代替新策略的线上随机验证。

## 4. Hillstrom 与 Criteo 的取舍

Hillstrom：64,000 行、三臂随机邮件、12 列、约 3.96 MB；安装负担低，天然支持日后多处理扩展。缺点是 2008 年邮件场景较旧、`conversion` 只有约 0.9%，并非现代广告竞价日志。

Criteo Uplift：来自广告 incrementality tests，约 2,500 万行，11/12 个匿名特征、treatment、visit/conversion，更贴近在线广告；但下载、内存、训练与迭代风险显著更高。当前 8 月 8 日 gate 前，吞吐和可解释性优先，所以锁定 Hillstrom；Criteo 不作为 D1-D4 的并行分支。

常见错误：

- 把三臂直接编码成一个 `T∈{0,1}`，无意中混合 Mens/Womens 两种处理。
- 把 `segment` 或处理后的 `visit/spend` 当普通协变量，造成 treatment/leakage。
- 将三臂均值差直接称作每个人的 ITE。
- 原始文件用 Excel 保存后改动拼写或编码，哈希失败；不要修改 `data/raw/`。
- 数据原值把 Suburban 拼成 `Surburban`；清洗时应记录映射，不要静默改原文件。
